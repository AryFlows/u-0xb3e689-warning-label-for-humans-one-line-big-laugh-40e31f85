Entry for the make.fun bounty [Warning Label for Humans: One Line, Big Laugh](https://make.fun/bounty/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85) — the funniest single-line safety warning label that should come printed on every human being, at most 160 characters.

## The label

> WARNING: This human runs on six hours of sleep and pure spite. Do not operate before coffee — may spontaneously start a podcast.

Verified locally: **128 characters** (130 bytes), one line, no trailing newline — inside the 1–160 character gate.

## Run

```sh
node main.ts
```

Writes the label to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Node 22+ required, standard library only.
